# ⏰ 歡樂時鐘小學堂 (Kids Clock Learning)

> 一款專為兒童設計的互動式類比與數位時鐘教學系統。模擬真實機械齒輪連動，去除秒針干擾，結合遊戲化釣魚獎勵機制，幫助小朋友在互動探索中輕鬆掌握時間觀念！

🔗 **線上體驗網址**：[https://will0605.github.io/kids-clock-learning-2/](https://will0605.github.io/kids-clock-learning-2/)

---

## 🌟 核心特色

### 1. 擬真實體機械齒輪連動 (無秒針專注設計)
- **純時針與分針**：去除跳動的秒針，降低視覺干擾，協助初學者專注理解時與分的關係。
- **1:12 機械聯動**：分針旋轉每圈 ($360^\circ$)，時針平滑前進一個大格 ($30^\circ$)。
- **量化離散步進**：以 1 分鐘為單位俐落跳動，徹底杜絕浮點數小數點困擾。
- **大字與輔助刻度**：具備清晰的 1~12 小時標記，以及可自由開關的 5, 10, 15... 60 分鐘外圈提示。

### 2. 三大循序漸進學習任務
- **🎯 任務一：看鐘報時 (類比 ➔ 數位)**
  - 隱藏數位時鐘與設定列防洩題，專注觀察指針。
  - 支援「任意隨機整數分鐘 (如 12分、28分)」與「5分倍數」雙難度切換。
  - 支援鍵盤快速 Enter 跳轉提交，行動端自動彈出大字九宮格數字鍵盤。
- **🛠️ 任務二：撥鐘挑戰 (數位 ➔ 類比)**
  - 給定目標數位時間，小朋友手動拖曳分針撥至正確位置。
  - 智慧角度判定，提供精確容錯與指引提示。
- **📝 任務三：看鐘選時間 (四選一選擇題)**
  - 自動生成具備教學意義的干擾選項 (如快一小時、慢一小時、分鐘微差)。
  - 四顆大按鍵直覺點擊，即時給予色彩與音效視覺回饋，特別適合低幼學童。

### 3. AM / PM 與 24 小時制無縫轉換
- 支援一鍵在「12 小時制 (上午 AM / 下午 PM)」與「24 小時制」之間雙向切換。
- 類比鐘面維持真實物理指針位置，強化兒童對於「下午 3:00 就是 15:00」的抽象時間轉換認知。

### 4. 遊戲化激勵：釣魚池與夢幻水族箱
- **答對題目獎勵魚餌**：首次答對題目即獲 1 次釣魚機會，防止重複刷分。
- **加權隨機釣魚池**：收錄 10 種不同稀有度海洋生物（★ 活潑小金魚 到 ★★★★★ 古代時鐘秘寶箱）。
- **水族箱圖鑑與本地持久化**：使用 `localStorage` 自動保存收集進度與剩餘魚餌，重新整理不丟失。
- **家長 / 教師管理安全鎖**：水族箱設有密碼重置機制（預設密碼：`8888`），防止小朋友誤清圖鑑。

### 5. 手機與平板全方位觸控優化 (Mobile Friendly)
- **大觸控熱區**：分針末端擴充半徑 24px 透明觸控區域，手指粗也不易滑脫。
- **防止滾動衝突**：透過 Pointer Capture 鎖定手勢，滑出鐘面依然平滑旋轉。
- **微震動觸覺回饋 (Haptics)**：撥動分針時模擬實體齒輪微震動，答對時釋放慶祝震動。
- **自適應排版**：窄螢幕自動啟用 2x2 緊湊按鈕網格與流體縮放，支援 iPhone 底部安全區域。

## 🚀 快速開始

本專案為**零外部依賴、純前端 Single Page Application**，無須任何建置工具 (No Node.js / Webpack / Vite 需求)：

1. **複製專案庫**：
   ```bash
   git clone https://github.com/will0605/kids-clock-learning-2.git
   ```
2. **直接開啟**：
   以任何瀏覽器雙擊開啟 [`index.html`](index.html) 即可開始使用！

## 🛠️ 技術架構

- **畫面渲染**：HTML5 + 原生向量 SVG (Scalable Vector Graphics)
- **樣式佈局**：純 CSS3 (Flexbox, CSS Grid, Media Queries, CSS Keyframes)
- **邏輯控制**：原生 Vanilla JavaScript (ES6+)
- **硬體與本地 API**：
  - [Web Pointer Events API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events) (Pointer Capture)
  - [Web Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API) (觸覺齒輪回饋)
  - [Web Storage API](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) (`localStorage` 資料持久化)
- **部署平台**：GitHub Pages (自動化部署)
